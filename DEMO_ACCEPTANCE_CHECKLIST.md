# Public Demonstrator Acceptance Checklist

- [ ] One-sentence question answered by the demo
- [ ] Public entry point works without private credentials
- [ ] Expected output documented
- [ ] Failure case documented
- [ ] Limits documented
- [ ] No enabling patent detail
- [ ] No unmeasured performance claim
- [ ] No customer / partner confidential data
- [ ] Proof artifact is code, output, hash, ledger or protocol — not only marketing imagery
